# Trondheim Bygg Service AS — Website Demo

A demo website built for a fictional staffing company
in Trondheim, Norway.

Built to showcase a typical business website with contact
form, company presentation and services section.

## Live Demo

[trondheimbyggserviceas.mateusz-malicki96.workers.dev](https://trondheimbyggserviceas.mateusz-malicki96.workers.dev/)

## Features

- Company presentation
- Services section
- Projects portfolio
- Contact form with success feedback
- Fully responsive design

## Tech Stack

React 19 · TypeScript · Cloudflare Workers · Vite · EmailJS

## Running Locally

### Prerequisites
- Node.js 20+
- pnpm
- Cloudflare account (for deployment)

### Installation

```bash
# Clone the repository
git clone https://github.com/mmalicki-dev/bpstrondheimas.git
cd bpstrondheimas

# Install dependencies
npm install

# Start development server
npm dev

# Deploy to Cloudflare Workers
npm deploy
```
